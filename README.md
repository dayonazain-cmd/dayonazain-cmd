#### 1. [Indonesia Multi-Asset Market Analytics](https://github.com/dayonazain-cmd/indonesia-financial-timeseries)
An end-to-end Data Science project analyzing Indonesia and global financial markets (2010-2026). 
*   **Key Features:** Data auditing, Machine Learning (XGBoost) for market direction, GARCH volatility modeling, and Markowitz Portfolio Optimization.
*   **Tech Stack:** Python, XGBoost, Statsmodels, Plotly, Streamlit.
*   **Live Demo:** [View Live Dashboard](https://indonesia-financial-timeseries-mgu2o4muzttrslg9zaitjf.streamlit.app)

Predictive modeling of rice production in Indonesia. Utilizes ensemble learning to identify key agricultural factors.
